| Attribute | Details |

<details>
<summary><b>⬡ &nbsp; QuerySense — AI-Powered SQL Generation Engine</b></summary>
<br/>

A natural language to SQL translation engine that enables non-technical users to query relational databases through conversational prompts. Built with a RAG pipeline using schema-aware embeddings to ensure structurally valid, context-accurate SQL generation.

<p align="center">

| Attribute | Details |
|:---|:---|
| **Stack** | Python · FastAPI · LangChain · PostgreSQL · pgvector · OpenAI API · Redis · React |
| **Scale** | Supports schemas with 200+ tables via chunked schema indexing and vector retrieval |
| **Performance** | Average query generation latency of 1.2s · schema cache reduces token usage by 60% |
| **Security** | Query sandboxing via read-only DB roles · SQL injection prevention layer · API key auth |
| **Impact** | Reduced analyst SQL iteration cycles from hours to seconds in internal testing |
| **Repository** | [github.com/AbdellahBouabdli/querysense](https://github.com/AbdellahBouabdli) |

</p>

The system vectorizes database schema definitions (tables, columns, foreign keys, constraints) and stores them in pgvector. At inference time, relevant schema fragments are retrieved via cosine similarity and injected into a structured prompt alongside the natural language question. A post-generation validator executes an EXPLAIN ANALYZE against a sandboxed read replica to verify query correctness before returning results to the caller.

<br/>
</details>

The anomaly detection module applies statistical control charts (Z-score, CUSUM) to flag deviations from rolling baselines. Alert routing supports multi-channel delivery via email, Slack webhooks, and PagerDuty integration.
